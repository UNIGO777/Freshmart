# ZipBasket Backend

Node.js backend scaffold for the ZipBasket service-based architecture in `Plan.md`.

## Setup

```sh
npm install
cp .env.example .env
docker compose up -d
```

## Structure

- `gateway/` API gateway
- `services/` domain services
- `shared/` reusable database, utility, and constant modules
- `docs/` backend documentation
